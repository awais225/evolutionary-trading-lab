PURPOSE OF THIS FILE
--------------------
This file is the LMSArena-side implementation/testing/commit history.

It is deliberately separate from chatgpt.txt:

    chatgpt.txt    = WHAT THE USER / CHATGPT REQUESTED  (requested-change history)
    lmsarena.txt   = WHAT LMSARENA ACTUALLY DID         (implementation history)

Rules for this file:
  * Append a new dated ENTRY per LMSArena iteration. Never rewrite old entries.
  * Record facts only: commands executed, results observed, files changed,
    commits, and remaining problems. Do not record secrets or credentials.
  * Research DATA must never be committed to Git and is never stored in the
    coding workspace; it lives in LMSArena temporary storage and is referenced
    through the EVOLUTIONARY_LAB_DATA_ROOT environment mechanism.

5. DATA-ROOT CONFIGURATION
--------------------------
The project already supports a configurable data root: backend/app/paths.py
reads EVOLUTIONARY_LAB_DATA_ROOT and derives every persistent path from it.
Two minimal, portable source changes were required so the rest of the
application follows the same root (no sandbox path is hard-coded anywhere):

  * backend/app/config.py — new helper `_resolve_data_tree()`: any configured
    path inside the DATA tree (data.data_root, data.cache_dir, database_path)
    is re-rooted onto paths.DATA_ROOT. Additionally, if the configured database
    file does not exist but the DATA_ROOT database does, DATA_ROOT is followed
    (prevents creating a competing/partial database).
  * backend/app/doctor.py — the DATA-root diagnostic now reports
    paths.DATA_ROOT instead of a hard-coded <root>/DATA.

Portability verified both ways:
    EVOLUTIONARY_LAB_DATA_ROOT set   -> data_root, cache_dir and database_path
                                        resolve inside temporary storage,
                                        database exists = True
    unset                            -> resolution is identical to upstream
                                        behaviour (<root>/DATA)

Runtime invocation:
    EVOLUTIONARY_LAB_DATA_ROOT=/opt/lmsarena-storage/DATA \
    python -m uvicorn app.main:app --host 0.0.0.0 --port 8787

A helper for future iterations was added: scripts/lmsarena_provision_data.sh
(imports DATA verbatim into LMSArena temporary storage, verifies the population,
never writes into the workspace, stores no credential).
